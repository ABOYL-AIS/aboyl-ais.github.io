这是当前正在持续打磨的个人网站项目，也是整个仓库本身所对应的真实作品。

项目目标并不是简单拼一个模板站，而是把“个人介绍、项目展示、研究记录、笔记归档、图集收藏”统一到一个长期可维护的静态站结构里，同时保留清晰的内容边界和更个人化的气质。

## 项目重点

- 以 `Astro + Tailwind CSS` 搭建静态内容站
- 保持中文根路径与英文 `/en/` 双语路由
- 使用 `Content Collections` 管理 projects、research、notes、gallery 四类内容
- 统一处理 `GitHub Pages` 与 `Vercel` 的部署路径兼容
- 通过共享布局、组件和数据配置减少后续维护成本

## 当前完成的内容

- 首页、About、Projects、Research、Notes、Gallery、Contact、404 页面已经建立
- Header、Footer、主题切换、语言切换、卡片系统与详情页模板已经统一
- 首页已经形成较完整的信息节奏，包括 Hero、Bento 入口、精选内容与图集预览
- 站点已经可以本地构建，也能部署到 GitHub Pages 与 Vercel

## 这个项目对我来说的价值

这个项目不是一次性的展示页，而是后续所有公开表达的承载空间。

我希望它既能承担正式展示的角色，又不失去个人表达的温度；既能继续扩展新的内容模块，又不因为功能增长而变成失控的模板拼接。

## 后续方向

- 继续替换占位内容，补充更真实的项目、研究与笔记
- 进一步优化标题、卡片比例与页面节奏
- 补全品牌资源、社交预览图和更稳定的视觉识别
- 让内容与风格保持同步升级，而不是各自漂移
