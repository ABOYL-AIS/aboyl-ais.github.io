This project focuses on the site's long-term evolution. The goal is not to stack pages quickly, but to establish a stable visual skeleton, component system, and content model first.

- The site remains static-first
- Content stays separate from presentation
- The page structure can grow into blog, project, gallery, or journal layers

When a new reference template is introduced later, only local components and visual language should need to change instead of the entire foundation.
